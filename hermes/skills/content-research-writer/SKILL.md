# Content Research Writer

Skill de coautoria para criar conteudo de alta qualidade.

## Quando Usar

- Escrever posts para X/Twitter com alto engajamento
- Criar material didatico para cursos (roteiros, aulas)
- Landing pages e paginas de venda
- Email marketing e newsletters
- Conteudo para blog ou documentacao

## Fluxo de Trabalho

### Passo 1: Briefing
Entender o publico-alvo, formato e objetivo do conteudo.
- Quem vai ler? (devs, iniciantes, empreendedores)
- Qual o formato? (thread, post, artigo, aula)
- Qual o objetivo? (vender, educar, engajar)

### Passo 2: Pesquisa
Antes de escrever, pesquisar:
- Dados e estatisticas recentes sobre o topico
- Concorrentes e o que ja foi publicado
- Referencias para citacoes
- Palavras-chave para SEO

### Passo 3: Estrutura
Organizar em:
- **Hook**: Primeira frase que prende atencao
- **Problema**: A dor que o conteudo resolve
- **Solucao**: O que o leitor vai aprender
- **CTA**: O que fazer depois de ler

### Passo 4: Escrita
- Tom: profissional mas acessivel (sem girias, sem robotico)
- Voz ativa, frases curtas, paragrafos de 2-3 linhas
- Exemplificar com casos reais

### Passo 5: Revisao
Para cada secao, perguntar:
- Essa informacao e util? (senao, cortar)
- O leitor vai entender? (senao, simplificar)
- Isso gera engajamento? (senao, reescrever)

## Templates

### Post para X (alta performance)
```
[Linha 1 - Hook] Afirmacao forte ou dor compartilhada
[Linha 2-3 - Desenvolvimento] Experiencia especifica com dados
[Linha 4 - CTA] Pergunta que convida ao reply
```

### Thread educativa
```
Tweet 1: Gancho + visao geral
Tweet 2-4: Conteudo principal (1 ideia por tweet)
Tweet 5: Resumo + CTA
```

### Landing page de curso
```
Headline: Promessa clara do que o aluno vai conseguir
Subheadline: Para quem e (publico-alvo)
Topicos: O que o curso cobre (6-8 itens)
CTA: "Comprar por R$ XX" (visivel, sem rodeios)
Prova social: Depoimentos ou numeros
FAQ: Responder objecoes comuns
```

## Regras de Tom

- Nao usar "1️⃣2️⃣3️⃣" ou menus numerados em respostas
- Nao se identificar como "assistente" ou "bot"
- Linguagem natural que parece humana
- Profissional sem ser formal demais
- Direto ao ponto sem rodeios
